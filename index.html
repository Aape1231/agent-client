Assistant API 規格說明

基於 OpenAI 相容架構的內部助理 API 介面文件。

目錄

  • 認證與 Base URL
  • Chat Completions
  • Threads
  • Files
  • Rate Limits
  • 錯誤代碼

認證與基礎資訊

Header: Authorization: Bearer <api_key>

API Base URL

環境URL
Sandbox (SBX)https://rtgapp.profetai.com:4231/public/kits/openai
Production (PRD)https://rtgapp.profetai.com:4234/public/kits/openai

Chat Completions

POST /v1/chat/completions

欄位型別必填說明
modelstring是Assistant ID (支援 assistant: 前綴)
messagesarray是對話內容 (Role: user/assistant)
thread_idstring否Session ID (支援 thread- 前綴)
streamboolean否(目前 Controller 固定回 JSON)
toolsarray否保留欄位 (目前 Service 未使用)

Response Choice 欄位

  • message.content: 輸出文字
  • finish_reason: 固定 stop
  • usage: Token 統計資訊 (若可取得)

Threads (Sessions)

List Threads

GET /v1/threads

參數說明預設
limit數量限制50
order排序desc

List Messages

GET /v1/threads/{thread_id}/messages

參數說明
limit數量限制 (預設 50)
order排序 (預設 asc)
afterPagination cursor
beforePagination cursor

Delete Thread

DELETE /v1/threads/{thread_id}

Files (檔案)

POST /v1/files

Content-Type: multipart/form-data

欄位型別必填說明
fileFile是實體檔案
purposestring否預設 assistants
is_tempboolean否預設 false

Rate Limits

成功或超額回應皆會包含以下 Headers:

  • X-RateLimit-Limit-Requests
  • X-RateLimit-Remaining-Requests
  • X-RateLimit-Reset-Requests

錯誤代碼說明

HTTPCode說明
401invalid_api_keyAPI Key 無效
403api_key_disabledAPI Key 已被停用
429rate_limit_exceeded超過請求速率限制 (請等待 Retry-After 秒數)
429controller_throttleController 忙碌中
503database_busy資料庫連線超過閥值
503database_saturated資料庫連線已滿
504database_timeout資料庫查詢逾時
503chat_interrupted等待可用插槽時被中斷

v14.2 2026-10-07
  • API 沒有取消回應的端點，因此移除原本無效的「停止」鈕與 Esc 中止，避免看起來能中止

  • 處理中關閉／重新整理頁面會先提醒，避免遺失回覆

  • 助理訊息新增 { } 檢視原始回應 JSON；程式碼範例改用 YOUR_API_KEY
v12.0

v9–v11
